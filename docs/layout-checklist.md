## 本轮修复

- `Download Properties` 是嵌入在更长字面量里的窗口类/标题，新增偏移词条 `0x16640C`，窗口标题变为“下载属性”。
- 新链接对话框的 `Download` 按钮同样是嵌入字符串，新增偏移词条 `0x1670C0`，按钮变为“下载”。
- `Segment` 统一为“分段”，临时目录文案改为“临时分段文件”。

## 仍保持英文（已文档化）

- 状态列 `Complete` / `Paused` / `Error` 和日期月份：数据库/区域设置依赖。
- About 的更新状态、`Contact` / `Website`：等长填充失败，按约定回退英文。
- 浏览器名、产品名、版本号、协议名、排序标记：专有名词/格式标记。
- 属性对话框里的 `Bytes` 单位：嵌入在复合格式串中，精确字符串替换无法单独命中。
