# 退出码

补丁引擎 `ndm_patch.ps1` 的稳定退出码：

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功；`status`/`audit`/`verify` 全部通过，或 `apply` 完整应用 |
| `2` | 检测到 NeatDM 正在运行，拒绝覆盖 |
| `3` | 找不到与当前版本匹配的原版备份，拒绝恢复/使用 |
| `4` | 原版备份校验失败，可能已损坏 |
| `5` | 部分成功：`apply` 有未匹配/超长/重叠项，或 `verify` 仍有未汉化项 |
| `6` | 当前 exe 已含汉化文案且没有该版本原版备份，拒绝创建备份 |

版本策略：

- 词条表针对 `1.4.24`；`-TargetVersion` 可覆盖，用于新版本报告。
- 原版备份存放在 `originals/`，文件名包含版本和哈希前缀，清单为 `originals/manifest.tsv`。
- 旧版单文件备份 `NeatDM.英文原版.exe.bak` 会在首次运行时迁移到 `originals/`。
- 恢复只匹配当前 exe 的版本；没有匹配项时拒绝，避免降级。
