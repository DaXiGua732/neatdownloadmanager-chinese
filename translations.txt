# 1) 下载状态列 Complete / Paused / Error
#    这三个是数据库 status 字段的取值，界面直接读出来显示，
#    同时又被 SQL 语句 status = 'Complete' 引用，改了会导致列表查询失效。
#
# 2) Contact / Website 两行（About 对话框）
#    NDM 会从 "Contact : support@neatdownloadmanager.com" 与
#    "Website : neatdownloadmanager.com" 里截取域名来生成超链接，
#    改动前缀会让蓝链错乱显示，因此保持原样。
#
# 3) 日期里的月份缩写（Oct 18 ...）
#    走的是 Win32 系统区域设置，不读 exe 里的运行库语言表，无法通过改二进制实现。
#    想让日期显示成中文，请改 Windows 的「设置 → 时间和语言 → 语言和区域」区域格式。
