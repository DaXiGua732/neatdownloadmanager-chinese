# 只做字符串层汉化，不修改程序代码

NDM 1.4.24 把界面文案硬编码为 UTF-16LE 字符串，没有语言包。补丁采用原地覆写：中文写进原字符串槽位，剩余字节补零，PE 结构不动。布局敏感的独立字符串可以补空格；动态拼接字符串不补。状态值、日期、About/Contact 以及无法用精确匹配命中的嵌入片段保持英文。

这样做的原因是：补丁必须能在一份未签名的 exe 上安全回滚、跟随 NDM 小版本重打，并且不改变下载/协议/数据库行为。修改布局算法或状态映射会把这些保障变成版本相关的代码补丁；等长填充在 About 上实测失败后，按约定回退英文，而不是引入代码补丁。

后果：About 的更新状态和 Contact/Website、状态列、日期月份、`Bytes` 单位以及专有名词仍是英文；这些都已记录在用户指南和布局清单中。
